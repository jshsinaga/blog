# Joshua's Blog

Personal blog built with Astro, Tailwind CSS, and Astro Content Collections.

## Commands

```bash
bun install
bun run dev
bun run check
bun run build
bun run preview
```

## Features

- Markdown blog posts
- Content collections
- Blog archive with search, category filter, and pagination
- Blog detail pages with table of contents
- RSS feed
- Sitemap and robots.txt
- Dark/light mode
- Smooth scrolling with Lenis, respecting reduced-motion preferences
- Responsive Tailwind design
