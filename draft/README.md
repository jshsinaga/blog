# Drafts

Unfinished blog posts and rough ideas live here before they are ready to publish.

## How it works

- When starting a content session, check this folder first and offer existing drafts as the initial option.
- To publish a draft, move the file to `src/content/blogs` and follow `docs/BLOG_WRITING_SPEC.md` (file naming, frontmatter, images, tone, and validation).

See `docs/BLOG_WRITING_SPEC.md` for the drafting and publishing workflow.
